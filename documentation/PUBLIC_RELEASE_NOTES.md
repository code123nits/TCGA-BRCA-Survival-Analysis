# Public release notes

This repository is a research draft, not a peer-reviewed publication. The original processed input files and raw-to-matrix build workflow are not included. The archived bootstrap can be recomputed from `results/test_predictions.csv`; the original model fits have not been independently reproduced.

The prediction file uses sequential row labels in place of TCGA case IDs. The survival outcomes and numerical predictions are unchanged. No row-to-case mapping is provided. Public TCGA data remain subject to their original access and use conditions.

The original test split has been inspected repeatedly; it must not be treated as pristine confirmation. Fixed penalties lack a documented original selection rationale. Bibliographic verification and independent validation remain outstanding.
